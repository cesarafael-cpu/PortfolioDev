## 🚀 Sobre o Projeto

Este projeto foi criado com o objetivo de reunir em um único lugar informações sobre minha carreira, tecnologias que domino e projetos desenvolvidos durante meus estudos e prática profissional.

O site foi desenvolvido com foco em:

- Design responsivo
- Boa experiência do usuário (UX)
- Organização visual
- Performance
- Acessibilidade
